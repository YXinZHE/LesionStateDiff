# Repository Structure

This repository contains the source code and supporting files for **LesionStateDiff**.

## Directory Structure

```text
LesionStateDiff/
├── configs/
├── docs/
├── scripts/
├── src/
│   └── lesionstatediff/
├── tests/
├── CITATION.cff.template
├── PUBLIC_RELEASE_AUDIT.md
├── README.md
├── pyproject.toml
└── requirements.txt
```

## Directory Description

### `configs/`

Configuration files used by the project.

### `docs/`

Project documentation and supplementary usage notes.

### `scripts/`

Executable scripts for running project-related workflows.

### `src/lesionstatediff/`

Main source code of **LesionStateDiff**.

This directory contains the core implementation of the project.

### `tests/`

Test files used to verify the implementation and basic functionality of the codebase.

## Root Files

### `README.md`

Overview of the repository structure and project files.

### `requirements.txt`

Python package dependencies required to run the project.

### `pyproject.toml`

Python project configuration and package metadata.

### `CITATION.cff.template`

Template for citation metadata.

The final citation information will be updated when the corresponding paper becomes publicly available.

### `PUBLIC_RELEASE_AUDIT.md`

Checklist and notes used to review the repository before public release.

More detailed documentation for individual components will be added as the repository is prepared for full release.
