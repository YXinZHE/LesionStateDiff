# Public release checklist

- [x] Core LSDM and PSC source included.
- [x] Training and generation entry points included.
- [x] Patient data, images, masks, weights, and logs excluded.
- [x] Server addresses, credentials, and absolute experiment paths excluded.
- [x] Input/channel contract documented.
- [x] Actual learning-rate lineage documented.
- [x] Test-set leakage guards retained.
- [ ] Confirm authors and repository URL in `CITATION.cff.template`.
- [ ] Select a license after checking upstream obligations.
- [ ] Publish permitted checkpoint download links and SHA256 values, if any.
- [ ] Add dataset access instructions consistent with ethics approval.
- [ ] Add the accepted paper citation and DOI.
